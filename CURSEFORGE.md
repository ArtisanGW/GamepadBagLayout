# Gamepad Bag Layout

With the controller UI on, the game's bag window puts each bag's button (its free slots, its menu) right after that bag's items, so they end up scattered across the window. Gamepad Bag Layout groups them at the top.

- The backpack's button stays where the game puts it; bag 1, bag 2 and the others follow it, right to left, then the keyring's
- Nothing is replaced: the buttons are the game's own, with their counts, menus and controller navigation
- Works in a fight too
- One setting, on by default: Options > AddOns > Gamepad Bag Layout, or /gbl

A vanilla addon: it needs no other addon.
